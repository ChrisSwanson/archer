# When can a carrier leave?

A wing mark selects a service class; a gate decides when the carrier can leave. Who decides the “proper time”?

Open this directory as an Archer project with `archer.toml`, then read the [Protocol Casebook](.archer/notes/reading-guide.md). Open [A Pecking Order With Queues](.archer/diagrams/qos-queues.mmd), choose **Walkthrough**, and start **From wing mark to departure**.

Then select **Proper time** and comment with the scheduling assumption you want your agent to check. The second case asks what the traffic picture actually shows. Both keep exact excerpts beside labelled agent interpretation and explicit gaps.

The [RFC 1149](.archer/notes/rfc1149.md) and [RFC 2549](.archer/notes/rfc2549.md) notes remain unchanged. `sources/` contains the original plain-text RFCs. These historical April 1 memos do not become a new implementation specification here.
