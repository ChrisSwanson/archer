# IP over Avian Carriers example notices

The preserved RFC notes and `sources/` files are historical documents. The reading guide, diagrams, recipes and walkthrough prose are agent-authored explanatory derivatives. They do not modify or supersede the RFCs. RFC 1149 says distribution is unlimited in Status of this Memo; its terms are not inferred from RFC 2549.

## Distribution of figures and sidecars

Keep this notice with the complete example project. Independently distributed images must carry this full notice or be accompanied by it; a containing page/document may include the full statement instead. Archer's local SVG/PNG exports read this project's `NOTICE.md`, embedding it in SVG metadata or a PNG UTF-8 text chunk. Request `noticeCaption: true` to also draw the full notice below the image.

Image conversion or editing may strip that metadata; keep this file alongside converted or detached images that no longer carry it. Emphasis recipes and walkthrough JSON sidecars need this file alongside them; they embed no notice fields. A copyright comment in Mermaid does not survive every exporter.

Generated diagram pages display the applicable notice and provide it beside downloads. The source RFC notes remain byte-for-byte unchanged.
