# RFC 2324 Example: Distribution Notice

The official RFC note and `sources/rfc2324.txt` are preserved copies. The casebook, diagrams, walkthrough prose and highlight recipes are explanatory derivatives of RFC 2324, not a corrected RFC or an implementation specification. Archer's Apache licence does not replace the notice below.

Keep this full notice with independently distributed images, walkthrough sidecars and emphasis recipes. Archer's local SVG/PNG exports read this project's `NOTICE.md` and carry it in SVG metadata or a PNG UTF-8 text chunk. Request `noticeCaption: true` to also draw the full notice below the image. Generated site pages display the notice and make it available beside downloads.

Image conversion or editing may strip metadata. Include this file alongside converted or detached images that no longer carry the notice. JSON walkthroughs and recipes also need this file alongside them. A link or an invisible Mermaid source comment does not supply the full notice in an exported image.
