# Coffee: Can the Pot Honour This Request?

Start with **[Which additions can the pot refuse?](.archer/notes/reading-guide.md)** in the Protocol Casebook. Read one answer, inspect its RFC evidence, then test the interpretation.

Open [Brew Decisions](.archer/diagrams/brew-decisions.mmd) in Archer and choose the saved walkthrough **A Request Is Not a Promise**. Select the line to **406 Not Acceptable** and comment: “Does this line make an optional refusal look mandatory?” Ask your agent to answer from the source and improve the explanation.

The casebook also asks **What does this request name?**, with an inline URI figure you can open in the full canvas. Its **Try the interaction** section includes ready-to-run highlight recipes. On the public site, diagrams and walkthrough prose are static; selecting and commenting happen in Archer.

The [official RFC note](.archer/notes/rfc2324.md) and [plain-text RFC](sources/rfc2324.txt) remain unchanged. Interpretations live beside them. Open this directory as an Archer project using `archer.toml`.
