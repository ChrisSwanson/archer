# V5 state fixtures

`harness/surfaces.mjs` includes five isolated recipes:

| State | Fixture |
|---|---|
| `P3.offline` | Load a note, observe a native SSE open, then stop only its new sandbox. |
| `P7.offline` | Open project review, observe a native SSE open, then stop only its new sandbox. |
| `P7.loading` | Hold the real initial `api/comment-activity` request with project review open. |
| `P11.loading` | Submit Compare and hold its real `compare_diagrams` request. |
| `P4.read-only` | Copy the corpus with top-level `edit = false`, then issue an ordinary access link. |

Use the normal measurement tools' `--surfaces` selector. These recipes ignore the supplied target
and start a new owned sandbox per opening, with private writer state. They serve the existing
`ui/dist/index.html`, or `ARCHER_UI_STATES_PAGE`; they never build. No `r1`/`r1-base` mutation or stop.

`openState(page, state, target)` returns `evidence` with the actual origin, sandbox name and state
proof. Call `leaveState(page, state)` in `finally`, before closing the page/context. Failed setup
cleans itself up; page close also triggers cleanup. Loading requests are continued on leave;
`releaseV5Requests(page)` can continue them earlier to check the real response.

A reached fixture is not a passing V5 judgment. Offline evidence requires an already-open
`text/event-stream` response, completion/failure of that same request, and a native EventSource
error. Loading records the held URLs, visible text and live/busy attributes. This reveals missing
product cues instead of fabricating them. In the supplied pass-6 page, P3 has no reconnect cue and
P7 initial loading says “No discussions yet” without a loading/busy cue.

`--reader` alone omits authoring roots but does **not** enforce read-only access. ADRs 0025/0028,
amended October 28, permit any admitted cookie to edit when the project's edit switch permits it.
Use `P4.read-only` for a genuine read-only page. Its test verifies `403 editing_disabled` and unchanged
source bytes after a valid save attempt; the ordinary reader-link investigation belongs to R3.

Run: `node --test --test-concurrency=1 tools/devkit/test/*.test.mjs`.
