# Code of conduct

Archer follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Report unacceptable behaviour privately through the same channel as security reports, GitHub's
private vulnerability reporting: <https://github.com/chrisswanson/archer/security/advisories/new>.
Say in the title that it is a conduct report. Reports are read only by the maintainers and kept
confidential.
